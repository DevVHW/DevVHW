## 🚀 Projetos em destaque

### 💰 [Controle Financeiro](https://github.com/DevVHW/financeiro) · **[Demo online](https://controle-financeiro-80hf.onrender.com/)**
Aplicação full stack de controle financeiro com autenticação, dashboard e CRUD
completo. Backend com API REST, validação com erros por campo, valores
armazenados em centavos, senhas com scrypt, sessões em cookie HttpOnly,
proteção contra CSRF, rate limit e testes automatizados.
**Stack:** Node.js · Express 5 · SQLite · HTML/CSS/JavaScript

### 🍔 [Hamburgueria](https://github.com/DevVHW/Projeto-Hamburgueria) · **[Demo online](https://projeto-hamburgueria-seven.vercel.app)**
Site responsivo para pedidos de hamburgueria, com deploy em produção.
**Stack:** HTML · CSS · JavaScript · Tailwind CSS
